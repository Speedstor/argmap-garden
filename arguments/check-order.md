## Pinned terms

- `check`: Finding out whether one bet is true or false. Every check counts as 1, whatever effort it takes. Pinned in: `order-finds-flaw-sooner`, `reader-reruns`.
- `argmap-order`: The order in which argmap report lists the bets, worked out again after each check: bets that can change the conclusion alone first, then the shakiest label as read, then the highest cost of being wrong, then the widest reach. The command argmap next ranks by it. Pinned in: `order-finds-flaw-sooner`, `lead-on-made-up-maps`, `lead-on-public-map`, `unnamed-labels-erase-lead`, `unnamed-order-slower`.
- `file-order`: The bets from top to bottom, as the tool lists the claims of the file. Pinned in: `order-finds-flaw-sooner`, `unnamed-labels-erase-lead`.
- `made-up`: Generated by trials/check-order.mts: a conclusion, lines of support, bets with trust labels, and 2 objections that each have a rebuttal. Each bet is secretly false with a chance set by its label: observed 3%, corroborated 10%, track-record 25%, assumed 40%. Pinned in: `lead-on-made-up-maps`, `unnamed-order-slower`.
- `share`: The mean number of checks an order takes until the conclusion first matches the truth, divided by the same mean for file order, over the maps where the conclusion with nothing knocked out differs from the truth. The script prints it as shareOfFileOrder. Pinned in: `lead-on-made-up-maps`, `lead-on-public-map`, `unnamed-order-slower`.
